# Codex Cloud Test

This repository contains two small projects:

- **Task Manager website:** `index.html`, `style.css`, and `script.js` at the root. Serve this directory with a static web server to use the website.
- **Flutter Hello World app:** [`flutter_app`](flutter_app/README.md), with Android and iOS project files, a greeting screen, and widget tests.

The Flutter app is independent of the website. Follow its README to run tests,
build an Android APK, or run it on a connected mobile device.
